Option 1: Direct Import (Simplest)

Option 2: React Hook (Recommended)
──────────────────────────────────

  const { createWorkspace, loading, error } = useBackendAPI();
  
  return (
    <button onClick={() => createWorkspace({...})} disabled={loading}>
